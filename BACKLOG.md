# Backlog

## Job & Application Assistant

### BL-001: Load job ad and CV for context
- **Description:** Allow the user to load a job ad and a CV to provide context for application assistance.
- **Accepted inputs:** PDF, HTML, or plain text.
- **Sources:** Web URL or local file.
- **Status:** Done (DEV-001)



### BL-002: Load writing samples for style reference
- **Description:** Allow the user to load writing samples (e.g., motivation/cover letters) as a reference for the applicant’s writing style.
- **Accepted inputs:** Same formats as other supported files (PDF, HTML, or plain text).
- **Sources:** Web URL(s) or a local folder containing the files (the app loads all supported files from the folder), instead of selecting files individually.
- **Status:** Backlog

### BL-003: Generate customized CV and optional motivation letter
- **Description:** Generate a customized version of the CV, and optionally a motivation letter, tailored to the job ad while accurately reflecting the applicant’s experience.
- **Constraints/requirements:**
  - Match experience to the job ad to improve interview chances.
  - Content must be accurate.
  - May omit irrelevant content.
  - Must not invent or fabricate information.
  - Generated content must be saved as new text files.
  - Existing/original files must remain unchanged by the program.
- **Status:** Backlog

### BL-004: Chat UI for revisions and improvements
- **Description:** Provide a chat UI (reading area, input field, etc.) where the applicant can request revisions to generated content and improve it (e.g., by providing additional skills/career information).
- **Status:** Backlog
